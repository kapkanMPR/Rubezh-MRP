Рубеж — полный восстановленный проект AI-0.12.222-RecoveredFull
Android version code: 323. Unity Editor: 6000.3.16f1.

Это полный исходный Unity-проект с графикой, звуком, картами и инструментами.
Готового APK в архиве нет: Unity Editor и Android toolchain в среде восстановления отсутствуют.

УСТАНОВКА И СБОРКА
1. Скачать ВСЕ четыре файла Rubezh-0.12.222-FULL-part1-of4.zip … part4-of4.zip.
2. Распаковать все четыре ZIP в одну новую папку. Это самостоятельные ZIP-архивы;
   каждый содержит свою часть общей папки Rubezh-0.12.222-RecoveredFull.
   Открывать в Unity нужно эту общую папку с Assets, Packages и ProjectSettings.
   Не накладывать полный восстановленный проект на произвольную старую версию.
3. Открыть Unity 6000.3.16f1 с Android Build Support, SDK/NDK и OpenJDK.
   Дождаться импорта пакетов и ресурсов, выбрать Android в Build Profiles.
4. Выполнить «Рубеж → Тест Unity → Подготовить нативный контент» и дождаться завершения.
   Исходные 70 карт и 6718 спрайтов включены. Производные NativeMaps, 281 SpriteAtlas,
   текстуры глубины, Addressables-каталог и платформенные bundles создаются Unity.
   В проекте намеренно нет фиктивной отметки, будто эта подготовка уже выполнена.
5. Выполнить «Рубеж → Версия разработчика → Собрать APK».
   Для релизного варианта: «Рубеж → Релизный APK».
   Пользоваться меню проекта: оно выполняет проверки ресурсов и подготовку сборки.
   Обычная кнопка Build блокируется существующей защитой NativeMapBuildScope.

ЧТО СОХРАНЕНО И ВОССТАНОВЛЕНО
• Основная игра и StableMovingRender из актуального сохранённого исходника 221.
  При движении камеры окружение рисуется напрямую; при остановке переиспользуется
  завершённый проход статичного мира. Сохранено объединение масок и групп земли.
• Исправления 221a–221c: материалы, миграция ресурсов и подготовка Exterior.
• Восстановлено исправление 221d: зарезервированное HLSL-имя point заменено на
  worldPoint в RubezhBattleMasks.shader без изменения вычислений.
• Вернулась защита импорта атласов Texture2D из хотфикса 216. Оба актуальных
  импортера NativeUI/NativeExterior также явно задают двумерный тип текстуры.
• Утраченные правила ядра восстановлены в CoverWaitPolicy.cs, TacticalAI.cs,
  Soldier.cs: короткая перебежка LocalBound, её индивидуальное состояние,
  ContactLifetime и отсечение контактов с временем из будущего. Эти три файла
  совпадают с восстановленным проверенным базовым исходником побайтно.
• Уже сделанный гибридный полигон сохранён вместе с основной игрой: карта 36×24,
  объёмные стены/крыши/объекты, разрушение тестовой стены и 10/50/100 демонстрационных
  бойцов. Вход из лагеря через тестовый полигон. Это испытание отображения,
  демонстрационные бойцы в нём не заменяют боевой ИИ основной игры.
• Старые исходные изображения перенесены из runtime Resources в Editor/Art.
  Исходные байты сохранены; снижение разрешения/качества текстур не выполнялось.

ПРОВЕРКИ И ИХ ГРАНИЦЫ
Актуальный отчёт: Build/Reports/AI-0.12.222/validation.md и validation.json.
Проверены реальное C#-ядро, данные карт, восстановленное поведение и команды
рендера на переносимых API-контрактах. Карты 1 и 20 прошли по 1200 тиков
с 100 бойцами: по 50 с каждой стороны. Это проверка состояния, а не FPS.
Исходные ресурсы проверены отдельно: Build/Reports/Recovery222/full-source-content-audit.json.
Происхождение изменений и точные хеши находятся в той же папке и в
Tools/ProjectCheck/CoreRecovery222. MANIFEST-222.json содержит SHA-256 комплекта.

Unity Editor здесь не запускался. Реальный импорт, шейдеры движка, Android APK,
пиксельное сравнение и производительность телефона остаются непроверенными.
Причина последнего загруженного падения сборки исправлена в исходнике, но
это не равнозначно успешной повторной компиляции шейдера в Unity.
Отчёты и README с номером 221 или ниже являются историческими материалами.
Optimization220 помечен неприменимым к заменённому механизму кэша, а не пройденным.

КОНТРОЛЬ КОМПЛЕКТНОСТИ
По желанию, при установленном Python 3:
  python Tools/ProjectCheck/FullRecovery222/package.py --verify .
Это проверяет распакованные файлы по MANIFEST-222.json. Новые файлы, которые
Unity создаст при импорте, не мешают проверке, но изменённые исходники будут отмечены.
Отдельный Rubezh-222-Source-and-Checks.zip — облегчённая копия для анализа кода,
не замена четырём FULL-архивам и не установочный патч.
