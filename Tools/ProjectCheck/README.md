# Проверки текущего проекта

Запуск из любого каталога: `python Tools/ProjectCheck/run.py`.
Нужны Python 3, PyYAML и .NET SDK 8. DOTNET_ROOT позволяет указать установку SDK.

- audit.py: хеши сохранённых спрайтов, страницы, алиасы, ссылки каталога, активные головы/корпуса.
- AppearanceCheck.cs: внешность, совместимость состояний и программная отрисовка.
- Menu122Check.cs: переходы, окна, награды, удержание текстур только текущим деревом UI.
- Lifetime122Check.cs: загрузка/освобождение карт, звуков и музыки.
- Levels122Check.cs: все сюжетные и военные карты, загрузка нужных страниц, программный рендер, короткие симуляции и 50 на 50.

Contracts — заглушки API для автономных проверок. Они не заменяют Unity Editor и не измеряют реальную память GPU, кадры в секунду, касания или расположение интерфейса. Числа rgba_bytes относятся к размерам изображений, не к показаниям Unity Profiler. Проверки не являются полным балансным прогоном кампании.
