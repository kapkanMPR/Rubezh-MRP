Рубеж — редактор баланса

Запуск: START_EDITOR.cmd (Python 3). Сервер слушает только 127.0.0.1:8765.
Укажите корень Unity-проекта и нажмите «Загрузить из Unity».
Текущие значения читаются из исходников, а не из стартового шаблона.

Оружейные профили разделены по сторонам. РПГ, РШГ и подствольные выстрелы
настраиваются в спецоборудовании. Параметры без действующей привязки
к исходникам остаются справочными и не применяются.

«Сохранить профиль как…» сохраняет отдельный JSON; повторное имя получает
числовой суффикс. «Применить в Unity» проверяет, не изменились ли исходники,
и сохраняет резервные копии в BalanceEditorBackups. При конфликте повторно
загрузите настройки из Unity и перенесите свои изменения.
Перед применением остановите игру и закройте Unity Editor.
После применения проверьте баланс в игре и пересоберите APK.

Открытие HTML без локального сервера не даёт доступа к файлам проекта.
