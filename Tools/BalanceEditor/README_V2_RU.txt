Рубеж — редактор баланса

Командная строка

Для существующего профиля формата rubezh-balance-profile-v1 сначала
проверьте привязки к исходному коду из корня проекта:

    python Tools/BalanceEditor/apply_balance.py profile.json --dry-run

Чтобы применить проверенный профиль, выполните ту же команду без --dry-run.
Ключ --project задаёт путь к другой копии Unity-проекта. Перед записью закройте
Unity Editor. Командный инструмент сохраняет изменяемые исходники и профиль в
BalanceEditorBackup. Идентификатор 0.11.29 в формате профиля исторический.

Локальный API и веб-интерфейс

    python Tools/BalanceEditor/local_server.py

Сервер слушает 127.0.0.1:8765. Для графического интерфейса требуется
совместимый editor-v2.html рядом с local_server.py. Этот клиент отсутствует
в исходном комплекте 0.12.222. Локальный API и командный инструмент работают
без него.

POST /api/load принимает объект с полем project (корень Unity-проекта)
и возвращает текущие значения из C#, 12 профилей оружия, список параметров
без действующей привязки и ревизию. POST /api/apply проверяет ревизию
перед записью и сохраняет резервные копии в BalanceEditorBackups.
POST /api/save-profile сохраняет именованный JSON в BalanceEditorProfiles.
При конфликте ревизий снова загрузите значения перед применением правок.
