# Рубеж

Текущая сохранённая версия: **AI-0.12.222-RecoveredFull**, Android code **323**, Unity **6000.3.16f1**.

**Исходники и ресурсы ещё не импортированы в этот репозиторий.** Этот README фиксирует проверенный комплект для первоначальной загрузки.

## Полный проект

Скачать все четыре ZIP и распаковать в одну папку. Ссылки требуют доступа владельца к файлам ChatGPT.

- [Часть 1](https://chatgpt.com/library?file_id=libfile_fde3_f-eaa33918aeb8819197f851921b631ddf_f1d4f51dd9f881919b5cb635926364ba&account_id=personal)
- [Часть 2](https://chatgpt.com/library?file_id=libfile_fde3_f-18a55e91b3048191a20667d6241718e9_f1d4f51dd9f881919b5cb635926364ba&account_id=personal)
- [Часть 3](https://chatgpt.com/library?file_id=libfile_fde3_f-2264c9292e3c8191ac112b5337f8b496_f1d4f51dd9f881919b5cb635926364ba&account_id=personal)
- [Часть 4](https://chatgpt.com/library?file_id=libfile_fde3_f-47d81485e4208191989d24c2e584912d_f1d4f51dd9f881919b5cb635926364ba&account_id=personal)

Комплект включает основную игру, восстановленное поведение бойцов, StableMovingRender, исправления подготовки ресурсов и гибридный полигон.

## Сборка

Открыть полный проект в Unity 6000.3.16f1 с Android Build Support. Выполнить «Рубеж → Тест Unity → Подготовить нативный контент», затем «Рубеж → Версия разработчика → Собрать APK».

При восстановлении выполнялись переносимые проверки C# и ресурсов. Unity Editor, реальная компиляция шейдеров, Android APK и FPS устройства не проверялись.
