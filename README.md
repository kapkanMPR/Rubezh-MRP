# Рубеж — 0.12.223

Полный Unity-проект тактического автобаттлера. В эту версию входят кампания, ресурсы игры, боевое ядро, редактор и гибридный полигон. Боевая камера использует обновлённый рендер местности, зданий и масок перекрытия.

## Открыть и собрать

1. Скачайте исходники нужной версии на вкладке Releases или клонируйте репозиторий. В Unity Hub выберите папку проекта с каталогами `Assets`, `Packages` и `ProjectSettings`.
2. Откройте проект в **Unity 6000.3.16f1**. Для сборки под Android нужен модуль Android Build Support с SDK, NDK и OpenJDK.
3. Выполните **Рубеж → Тест Unity → Подготовить нативный контент**. Дождитесь завершения подготовки и импорта ресурсов.
4. Выберите **Рубеж → Версия разработчика → Собрать APK** для сборки с диагностикой или **Рубеж → Релизный APK** для игровой сборки. Код версии Android — **324**.
